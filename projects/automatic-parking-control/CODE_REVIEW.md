# 当前源码核对记录

此记录对应本目录发布的两个应用入口文件；保留原逻辑，不在作品整理时修改控制行为。

| 位置 | 代码事实 | 影响 |
| --- | --- | --- |
| 控制板 `process_action()` | `ACTION_WAITING` 返回 `ACTION_MOVING_Z` 并设置 `action_step=1`，但后者没有按 `action_step` 区分伸出与缩回；没有切入 `ACTION_RETURNING_Y` 的赋值 | 定义了返回状态，但当前动作链没有接通到返回阶段 |
| 控制板 `action_timer` | 在主循环调用中递减，没有与毫秒时基绑定 | 数值 1000 不等于稳定的一秒 |
| 控制板 `Motors_stop()` | 重新初始化 GPIO，没有明确复位六路使能输出 | 不能据此认定 `stop` 命令能够停止所有电机；各 `motorX_stop()` 则包含使能复位操作 |
| 控制板 `positions` | 四车位表使用的 `motor_id` 为 1、1、2、2；配套逻辑文本则将四车位分配给 M1–M4 | 程序与动作设计资料的车位执行器映射不一致 |
| 控制板目标判断 | 横/竖轴均接受中间或末端限位，没有针对目标车位选择对应限位 | 不能据此声称四个目标位置已经正确区分 |
| 控制板 SPI 接收中断 | 在更新位置状态前执行 OLED 显示和阻塞延时 | 增加位置事件处理延迟，不宜作为快速限位停机路径 |
| 控制板 `SysTick_Delay()` | 直接把 `72000*ms` 写入 SysTick LOAD，并改写 CTRL | LOAD 为有限位宽且 CTRL 的时钟选择变化，注释中的一秒不能直接作为实际时间依据 |
| 控制板串口解析 | 使用 `strstr()` 识别短命令；`OK` 滑动缓冲未明确保留字符串终止符，`+IPD` 未按声明长度完整分帧 | 应完善字符串边界与收包处理 |
| 采集板 `last_state` | `{1}` 仅把第一个元素初始化为 1，其余元素为 0 | 与“全部初始未按下”的注释不一致 |

整理范围为静态代码核对，未重新编译或进行实机循环测试。原目录的历史编译记录不能替代当前代码的实机验证。
