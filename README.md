## 从这些案例可以看到什么

- **结构设计**：把功能要求拆解为输送、翻转、分拨和传动等子机构，组织装配关系。
- **工程图与明细表**：整理零件尺寸、左右镜像关系、标准件规格及装配标号对应关系。
- **计算辅助设计**：用 MATLAB 比较载荷、几何、齿轮参数与安装空间，说明参数选择依据。
- **软件协同**：SolidWorks 建模与装配，CAD/CAXA 图纸整理，MATLAB 参数分析与结果输出。

## 阅读方式
